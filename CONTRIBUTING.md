# Contributing to Concord

Thanks for helping! Concord is a public beta, so bug reports are gold.

- **Bugs / ideas:** open an issue (templates included). Paste diagnostics from the in-app feedback button.
- **Code:** fork, `npm install`, `npm start` to run, `npm test` before a PR. Keep PRs small and focused.
- **Good first issues:** new model presets, Mac/Linux packaging, UI polish, docs.

Layout: `src/core` (coordinator, merge engine, leases, memory), `src/server` (REST, SSE, MCP), `src/agents` (model adapters, built-in team), `renderer/` (UI), `test/` (stress tests and benchmarks).
